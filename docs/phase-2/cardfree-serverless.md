# Card-free compute for the FastAPI backend — non-PaaS programmes (serverless / lite container programmes)

**Agent:** CardFreeServerless · **Date of all fetches: 2026-10-14** · Sibling scope: classic PaaS hosts are in `local://cardfree-paas.md` (Koyeb, Hugging Face Spaces, Render, Railway, Fly.io …) and are cross-referenced, not re-quoted here.

**Method.** Every claim below is quoted from the provider's own pricing / FAQ / docs page fetched today. Card question is answered first for every candidate. Items I could not confirm from a primary page are marked `[UNVERIFIED]` with the reason.

**Refresher on the requirement.** FastAPI/ASGI (Uvicorn), ~250–400 MB RSS, no ML libs, LLM calls over the public internet + Neon Postgres, per-submission requests of a few minutes, batches of 30–100 over 10–60 min, must still work at a defence months from now. No credit card ever, no VM, no SSH.

## 2. Direct answer: who can host this backend, who cannot, and why

**No durable card-free *non-PaaS* host for this exact FastAPI container exists in the checked set.**

- **Can host it, card-free, Python-capable — with a catch:** only **Red Hat OpenShift Developer Sandbox** (§2). It takes a Dockerfile/container and supports Python, requires no card ("It is free. There is no credit card required."), and gives TLS routes. It fails the durability test: the sandbox is a **30-day trial**, the cluster region is not published, and the HTTP timeout/quota are not documented by Red Hat. Acceptable for a demo if the app is exported and re-imported into a fresh sandbox before the defence — not acceptable as a "deploy once, still live months later" artefact.

- **Card-blocked outright (no card-free path at all):** IBM Cloud Code Engine (§1), Modal (§3), Google Cloud Run standard (§4), Azure Container Apps (§6), Oracle Always Free (§10), Alibaba Function Compute (§14), Tencent SCF (§15), Baidu (§16). For IBM and Azure the provider's own words say the card is for identity verification, and IBM's own docs say you still can use Lite/Free plans — but the account cannot be created without the card, so they are excluded by the owner's constraint. Note IBM Code Engine is the technically best fit of the whole set (Dockerfile, 600 s max request, 4 GB default memory, permanent monthly zero-cost tier) — it is excluded purely on the payment method.
- **Card-free but dies inside the demonstration window:** AWS Lambda (§7) — signup needs no payment method ("No."), always-free Lambda is 1 M requests + 400 k GB-s/month, and ASGI is possible via Lambda Web Functions — but the **Free plan expires after 6 months, the account is then suspended, and data is erased after 90 days**. Azure's free account (§6) similarly disables after 30 days, and Alibaba/Tencent trials run 3 months.
- **Card-free and permanent, but the wrong language/runtime:** Supabase Edge Functions (§11), Neon Functions (§12), Val Town (§13) all run TypeScript/Deno/Node handlers only. Neon Functions is otherwise the strongest card-free serverless platform available (15-minute TTFB, 2 GB memory, Singapore, permanent free plan) — it is excluded only because "Neon Functions currently run JavaScript or TypeScript on the Node.js runtime" and the backend must stay FastAPI/ASGI.
- **Card-free and Python-capable, but the resource envelope is wrong:** Cloudflare Workers Free (§8) genuinely supports FastAPI (Python Workers GA, built-in ASGI server) at zero cost and with no card, but Free gives **128 MB per isolate against ~250–400 MB RSS** and **10 ms CPU per request**, and Cloudflare Containers — the shape that would fit — is Workers **Paid** only. Rewriting the app into Workers-sized handlers is a different application; not proposed here.
- **Card-free Cloud Run, but not deployable by us:** Google Cloud Starter Tier (§5) needs no billing account or card, but it only accepts apps built in Google AI Studio Build mode, caps you at two services in one region, and excludes Google Workspace-account holders. It cannot take this repo's Dockerfile.

**Consequence for the build:** if the card constraint is absolute and the artefact must be alive at a defence months from now, the viable hosts are the **classic PaaS / container hosts** in `local://cardfree-paas.md` (Hugging Face Spaces is the obvious Docker+FastAPI candidate), or an explicitly time-boxed redeploy onto the Red Hat sandbox before the defence. None of the vendor free/lite *programmes* in this file satisfies card-free + durable + Python-ASGI + ≥250 MB memory simultaneously.

## 4. Time-limited / trial flags (artefact must survive a defence months out)

- **Red Hat OpenShift Developer Sandbox** — 30-day trial (renewable by signing up again; export/import documented).
- **AWS Free plan (Lambda)** — 6 months or until credits exhausted; "AWS suspends your account and any associated projects, and you will lose access to your resources and data"; data erased 90 days later.
- **Azure free account** — $200 credit and 30 days, then "your account and services will be disabled".
- **Alibaba Cloud Function Compute** — free trial quota 150,000 CU/month for 3 consecutive months, then pay-as-you-go.
- **Tencent Cloud SCF** — promotional free tier advertised as "up to 3 months free".
- **IBM Cloud $200 credit** — 30 days (Code Engine's own monthly zero-cost tier is *not* time-limited, but the account is card-gated).
- **Modal** — $30/month recurring credits, not a trial, but a payment method must be on file.
- Not time-limited: Neon Free ("permanent (not a trial)"), Supabase Free, Cloudflare Workers Free, Google Cloud Free Tier (needs billing account), Oracle Always Free (needs card).
