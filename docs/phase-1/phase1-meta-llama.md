# Meta Llama family — Indonesian-capability facts (all pages accessed 2026-10-06)

Scope: Llama 3.1 (8B/70B), 3.2 (1B/3B), 3.3 (70B), Llama 4 Scout, Llama 4 Maverick, plus any newer open-weight Meta model.

## Access/mirror caveat (affects every "Meta page" below)
- `https://www.llama.com/docs/model-cards-and-prompt-formats/`, `/llama3_1/license`, `/llama4/license`, `/llama/llama4/use-policy` all now **redirect to `developer.meta.com/ai/...` / `dev.meta.ai/...`**, which serve a **JS-only SPA**: the fetch returned only `<title>` (e.g. "Llama 4 Community License Agreement") and no body text. Verified 2026-10-06.
- Therefore license/model-card text below is taken from Meta's own GitHub raw mirror `meta-llama/llama-models` (primary Meta-authored files), and Hugging Face metadata. A live HF raw fetch of the model-card `README.md`/`LICENSE` returned **HTTP 401 (gated repos)** — so HF was used only for metadata (license tag, language tags), not full text.

## Newer open-weight Meta model as of 2026-10-06
- The newest open-weight Meta release is **not a "Llama"**: **Muse Glimmer 30B** (`meta-models/Muse-Glimmer-30B`), released August 2026 by "Meta Superintelligence Lab", **Apache-2.0** license. Source: https://huggingface.co/meta-models/Muse-Glimmer-30B (accessed 2026-10-06). Quote: "Meta Superintelligence Lab … Model Release Date: August 2026 … License: Apache 2.0". It is a 29.6B dense model (incl. ~1.8B vision encoder), context "131,072+", knowledge cutoff January 4, 2026.
- No Llama 5 / newer Llama-branded open-weights model was found on a live primary page (see Not verified).

### Llama 3.1 (8B / 70B)
- Model card URL (primary): https://github.com/meta-llama/llama-models/blob/main/models/llama3_1/MODEL_CARD.md and raw https://raw.githubusercontent.com/meta-llama/llama-models/main/models/llama3_1/MODEL_CARD.md (accessed 2026-10-06). HF repo: https://huggingface.co/meta-llama/Llama-3.1-8B-Instruct (metadata, accessed 2026-10-06; raw README/LICENSE = HTTP 401).
- License: **Llama 3.1 Community License Agreement** (custom commercial). Key restriction quoted verbatim (https://raw.githubusercontent.com/meta-llama/llama-models/main/models/llama3_1/LICENSE, accessed 2026-10-06): "If, on the Llama 3.1 version release date, the monthly active users of the products or services made available by or for Licensee, or Licensee's affiliates, is greater than 700 million monthly active users in the preceding calendar month, you must request a license from Meta". Also: "prominently display 'Built with Llama' on a related website, user interface, blogpost, about page, or product documentation"; and if you train/improve a model with it, "you shall also include 'Llama' at the beginning of any such AI model name". AUP incorporated: "adhere to the Acceptable Use Policy … (available at https://llama.meta.com/llama3_1/use-policy)".
- Params: **dense** — 8B and 70B (plus 405B in family). "optimized transformer architecture"; GQA = Yes.
- Context length: **128k** tokens (model card table).
- Bahasa Indonesia evidence: **Not an officially supported language.** Supported languages quote: "English, German, French, Italian, Portuguese, Hindi, Spanish, and Thai." No Indonesian benchmark score is published in the model card. Note in card: "Llama 3.1 has been trained on a broader collection of languages than the 8 supported languages." Independent data point from SEA-HELM (https://arxiv.org/html/2502.14301v1, Table A.1, accessed 2026-10-06): **Llama-3.1-8B-Instruct Indonesian (ID) = 53.4** (SEA average 39.7; "Supported SEA Languages: TH"); **Llama-3.1-70B-Instruct ID = 67.8** (SEA average 61.9; "TH") (Table A.2). Indonesian/Latin training data documented? **No** — card lists no Indonesian data/support; SEA-HELM `-` for Llama 3.1.
- Structured output: model card does not claim function calling; it reports tool use benchmark "Tool Use / BFCL v2". Prompts doc: zero-shot function calling described for the 3.1 family at https://raw.githubusercontent.com/meta-llama/llama-models/main/models/llama3_3/prompt_format.md ("format for zero shot function calling, introduced in llama 3.2" continues from 3.1). Provider claim: Cloudflare supports **JSON Mode** for `@cf/meta/llama-3.1-8b-instruct` — quote: "Workers AI supports JSON Mode, enabling applications to request a structured output response" (https://developers.cloudflare.com/workers-ai/features/json-mode/, accessed 2026-10-06). NVIDIA NIM page for Llama 3.3 (not 3.1) reports Structured Output "Not supported" — see 3.3.
- Determinism caveats: serving engines do not guarantee reproducibility by default. vLLM primary doc quote: "vLLM does not guarantee the reproducibility of the results by default, for the sake of performance." Reproducible outputs need `VLLM_ENABLE_V1_MULTIPROCESSING=0` (offline) or batch invariance; "vLLM only provides reproducibility when it runs on the same hardware and the same vLLM version." (https://docs.vllm.ai/en/stable/usage/reproducibility/, accessed 2026-10-06). Query batches can change results unless batch invariance is enabled (https://docs.vllm.ai/en/latest/features/batch_invariance/). Quantisation nondeterminism: [UNVERIFIED] as a single primary sentence.
- Free-host availability (verified 2026-10-06):
  - **Cloudflare Workers AI — YES (free tier).** Free allocation "10,000 Neurons per day at no charge"; `@cf/meta/llama-3.1-8b-instruct` and variants are listed and priceable (https://developers.cloudflare.com/workers-ai/platform/pricing/).
  - **Groq — NO.** `llama-3.1-8b-instant` is now labelled **Enterprise**, price "ContactSales", rate limits "ContactSales" (https://console.groq.com/docs/models, accessed 2026-10-06).
  - **OpenRouter — NO free variant.** The OpenRouter models API (https://openrouter.ai/api/v1/models, fetched 2026-10-06) lists `meta-llama/llama-3.1-8b-instruct` and `meta-llama/llama-3.1-70b-instruct` with **non-zero** prices and **no `:free` id**.
  - **Together AI — NO free Llama.** Pricing page lists only paid Llama tiers (e.g. "Llama 3 8B Instruct Lite $0.14/$0.14") (https://www.together.ai/pricing, accessed 2026-10-06).
  - **Hugging Face Inference Providers — marginal.** Free users get "$0.10" monthly credits (https://huggingface.co/docs/inference-providers/pricing, accessed 2026-10-06).
- Notes: This is the family the SEA-HELM paper evaluates as a baseline; Indonesian is not a supported language.

### Llama 3.2 (1B / 3B)
- Model card URL (primary): https://raw.githubusercontent.com/meta-llama/llama-models/main/models/llama3_2/MODEL_CARD.md (accessed 2026-10-06). HF repos: meta-llama/Llama-3.2-1B-Instruct, meta-llama/Llama-3.2-3B-Instruct (metadata via HF API, accessed 2026-10-06).
- License: **Llama 3.2 Community License Agreement** (custom commercial). Quote (https://raw.githubusercontent.com/meta-llama/llama-models/main/models/llama3_2/LICENSE): "If, on the Llama 3.2 version release date, the monthly active users … is greater than 700 million monthly active users in the preceding calendar month, you must request a license from Meta, which Meta may grant to you in its sole discretion". Same "Built with Llama" + leading-"Llama" naming + AUP-in-license clauses as 3.1.
- Params: **dense** — 1B (1.23B) and 3B (3.21B); shared embeddings = Yes; GQA = Yes.
- Context length: **128k** tokens (`8k` for the separately released quantized checkpoints).
- Bahasa Indonesia evidence: **Not officially supported.** Quote: "English, German, French, Italian, Portuguese, Hindi, Spanish, and Thai are officially supported." Model card multilingual table shows only Portuguese/Spanish/Italian/German/French/Hindi/Thai MMLU — **no Indonesian**. No Indonesian/Latin training-data statement. No Indonesian benchmark number found on a live primary page.
- Structured output: model card reports tool use (BFCL V2, Nexus) but no explicit function-calling claim. Zero-shot function-calling format is documented for the family at https://raw.githubusercontent.com/meta-llama/llama-models/main/models/llama3_3/prompt_format.md ("introduced in llama 3.2"). Cloudflare JSON Mode covers `@cf/meta/llama-3-8b-instruct` (that is Llama 3, not 3.2) — see pricing/JSON-mode docs above.
- Determinism caveats: same as 3.1. vLLM batch-invariance doc explicitly lists Llama 3.2 as validated: "Llama 3: Llama3.1 and 3.2 series, meta-llama/Llama-3.2-1B-Instruct, meta-llama/Llama-3.2-3B-Instruct" (https://docs.vllm.ai/en/latest/features/batch_invariance/, accessed 2026-10-06) — i.e. deterministic output is possible only when batch invariance is explicitly enabled and hardware/version held fixed.

  - **OpenRouter — NO free variant.** `meta-llama/llama-3.2-1b-instruct` / `-3b-instruct` present but priced, no `:free` id (API, 2026-10-06).
  - **Together AI — NO.** No Llama 3.2 on the pricing page.
- Notes: On-device-oriented checkpoints (ExecuTorch/ARM); QAT/SpinQuant variants reported.

### Llama 4 Scout (17Bx16E)
- Model card URL (primary): https://raw.githubusercontent.com/meta-llama/llama-models/main/models/llama4/MODEL_CARD.md ; HF: https://huggingface.co/meta-llama/Llama-4-Scout-17B-16E-Instruct (HF API metadata, accessed 2026-10-06; language tags include **id**). - License: **Llama 4 Community License Agreement** (custom commercial). Quote (https://raw.githubusercontent.com/meta-llama/llama-models/main/models/llama4/LICENSE): "If, on the Llama 4 version release date, the monthly active users of the products or services made available by or for Licensee, or Licensee's affiliates, is greater than 700 million monthly active users in the preceding calendar month, you must request a license from Meta, which Meta may grant to you in its sole discretion…". Naming/attribution: "prominently display 'Built with Llama'"; leading-"Llama" naming for derivatives.
- **EU restriction (Llama 4 only):** verbatim from the Llama 4 Acceptable Use Policy (https://raw.githubusercontent.com/meta-llama/llama-models/main/models/llama4/USE_POLICY.md, accessed 2026-10-06): "With respect to any multimodal models included in Llama 4, the rights granted under Section 1(a) of the Llama 4 Community License Agreement are not being granted to you if you are an individual domiciled in, or a company with a principal place of business in, the European Union. This restriction does not apply to end users of a product or service that incorporates any such multimodal models." (The license text itself does not contain the EU clause; it lives in the AUP.) The live `/llama/llama4/use-policy` page now only returns a JS shell.
- Params: **MoE** — 17B activated / **109B total** (sparse, 16 experts); natively multimodal (text+image in, text+code out).
- Context length: **10M** tokens (model card).
- Bahasa Indonesia evidence: **Indonesian IS a documented supported language.** Quote: "Supported languages: Arabic, English, French, German, Hindi, Indonesian, Italian, Portuguese, Spanish, Tagalog, Thai, and Vietnamese." Also "Llama 4 has been trained on a broader collection of languages than the 12 supported languages (pre-training includes 200 total languages)". No Indonesian-specific benchmark score appears in the model card (multilingual benchmark shown is TydiQA 31.5 avg/f1 and MGSM 90.6). Indonesian/Latin training data documented? **Support claimed (language list); no per-language corpus disclosure.** No Indonesian SeaBench/SEA-HELM/IndoMMLU number found on a live primary page (SEA-HELM current leaderboard no longer lists Llama models — see Not verified).
- Structured output: Meta's prompt-format doc documents tool calling — https://raw.githubusercontent.com/meta-llama/llama-models/main/models/llama4/prompt_format.md: "# Tool calling … All available functions can be provided either in the system message or in the user message", plus "The output supports multiple, and parallel tool calls natively". Provider claim: NVIDIA NIM page states for `llama-4-scout-17b-16e-instruct` — "Function Calling: Supported / Structured Output: Supported / Reasoning: Not supported" (https://build.nvidia.com/meta/llama-4-scout-17b-16e-instruct, accessed 2026-10-06). Cloudflare model page also lists "Function calling: Yes" (https://developers.cloudflare.com/workers-ai/models/llama-4-scout-17b-16e-instruct/).
- Determinism caveats: **MoE routing adds nondeterminism** — vLLM documents that its routing simulator "randomly selects experts for each token" and MoE training/inference routing can diverge even "under identical conditions" (https://arxiv.org/pdf/2510.11370v2; vLLM routing docs). vLLM reproducibility caveat applies (not guaranteed by default). Llama 4 is **not** in the vLLM batch-invariance validated model list. Batch/quantisation nondeterminism: quantized checkpoints provided; exact statement [UNVERIFIED]. Reasoning-mode nondeterminism: not applicable.

  - **Cloudflare Workers AI — YES (free tier).** `@cf/meta/llama-4-scout-17b-16e-instruct` ($0.27/$0.85 per M tokens) under the 10,000 Neurons/day free allocation — https://developers.cloudflare.com/workers-ai/platform/pricing/ and model page.
  - **NVIDIA NIM — trial only** ("NVIDIA API Trial Terms of Service"); free-credit amount [UNVERIFIED].
